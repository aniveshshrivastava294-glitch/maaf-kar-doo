HOW TO USE
1. Open script.js and edit the text inside "var C = {...}" (names, what happened, promises).
2. Add photos to the photos folder and list them in script.js.
3. Double-click index.html to preview in your browser.
4. To share it as a link, upload the whole folder free to Netlify Drop (app.netlify.com/drop), GitHub Pages, or Vercel.
Tip: send the link with a short, calm message, then talk in person too.
